# ¿Cómo te pareció el club? · Feminario

Formulario anónimo de feedback del Club. Cada respuesta llega a una Google Sheet por medio de un backend de Google Apps Script.

Ya está configurado: la URL del backend está dentro de `index.html`.

## Publicar
1. Copia `index.html` y la carpeta `fonts` al repositorio.
2. `git add .` · `git commit -m "Formulario club"` · `git push`
3. GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`.

(Opcional) Tipografía Mundo Moderno: guardar el archivo como `fonts/MundoModerno.woff2`.
